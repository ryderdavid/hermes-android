# Hermes (Material You fork) v2.1.31-you.15

App-wide pending-approval visibility, on top of [v2.1.31-you.14](v2.1.31-you.14.md).

## Fixed

- **Permission/approval requests no longer wait for a back tap.** Previously a
  pending approval only surfaced once you returned to the owning chat
  (`ChatScreen` was the only listener), so while you sat on the chat list, a
  project view, or another chat, a permission request arrived unnoticed.
- The app root (`main.dart`) now listens to the shared pending-approval store
  and shows an **"Approval needed" snackbar on any screen**, with a **Review**
  action that opens the owning session — where the usual approval bottom sheet
  presents and answers it. Repeated listener updates don't refire the same
  request (deduped by connection|session|request|choice).

## Implementation

- `lib/main.dart`: root `scaffoldMessengerKey`, listener on
  `pendingNotificationApprovals` (added in initState, removed in dispose),
  Review action routes via `_openNotificationSession`.

## Tests

- `flutter analyze` clean; full `flutter test` green (2138 passed).

## Also in this release

- `display.busy_input_mode` set to `steer` in the gateway config, and the fork
  code default in `hermes-agent` `gateway/run.py` is `steer` (takes effect on
  the next gateway restart), so the you.14 steer-send button now lands as
  mid-turn guidance by default. App settings surface for server-side config is
  tracked as epic `hmy-04k`.
