# Hermes (Material You fork) v2.1.31-you.4

Diagnoses and works around biometric-gate failures on the SUDO toggles, on top
of [v2.1.31-you.3](v2.1.31-you.3.md). OpenSpec change
`mac-fetch-sudo-credential`.

## Fixed

- **The biometric gate now says why it failed.** `BiometricGate` reports a
  precise outcome (`authenticated` / `notAvailable` / `cancelled` /
  `error(code)`) instead of a bare false. If `local_auth` errors on the device
  (e.g. `LockedOut`, `NotEnrolled`), the snackbar now reads "Biometric check
  failed (<code>) — re-enter the SUDO password to enable instead." and the
  save dialog opens as the fallback gate, so the toggle is still enableable.
  A genuine user cancel still shows "Enable cancelled — the toggle stays off."
- Tests cover all four gate outcomes and the error→password-fallback path.
