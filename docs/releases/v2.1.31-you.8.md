# Hermes (Material You fork) v2.1.31-you.8

Semantic summaries on tool activity cards, on top of
[v2.1.31-you.7](v2.1.31-you.7.md). Branch `feat/inline-html-artifact-preview`;
beads hmy-siw.

## Added

- **Tool cards say what they're doing**: every tool-use row now renders
  "Tool name: summary" — e.g. "Read file: lib/core/theme/hermes_theme.dart",
  "Terminal: flutter analyze", "Search files: gateway_activity" — phrased
  client-side from the arguments the gateway already ships with each tool
  event (`tool.start`/`tool.complete` and stored history rows; the redacted
  REST `label` preview is the fallback when no args arrive). The summary sits
  next to the tool name in muted regular text (the name stays bold), is
  capped at 3 lines collapsed and full when the card is expanded, and is
  included in the TalkBack label and the "Using …" turn-status line. Reloaded
  sessions show the same summaries.
- Long paths/URLs are tail-truncated so the file name survives; commands and
  queries are head-truncated. Sensitive argument keys (tokens, passwords,
  credentials, API keys) are never surfaced in a summary.

## Tests

- New `test/tool_activity_summary_test.dart` covers the phrasing matrix:
  curated primary args, generic fallbacks, truncation direction, list args,
  sensitive-key skipping, and the `delegate_task`/`clarify` special cases.
- `gateway_activity_test.dart` extended: summary parsing from `args` on
  `tool.start`, the redacted `label` fallback on the REST streaming path,
  summary persistence across `merge`, stored-result fallback, and card widget
  rendering with and without a summary.
- `flutter analyze` clean; full `flutter test` green;
  `tools/check_no_hardcoded_colors.sh` clean.
