# Hermes (Material You fork) v2.1.30-you.4

Adds topic icons for chats, on top of
[v2.1.30-you.3](v2.1.30-you.3.md) and based on upstream v2.1.30 (`63670ab`).
The OpenSpec change is `openspec/changes/chat-topic-icons`.

## New

- **Chat icons.** Settings › Appearance › Chat icons has three choices:
  - **Letter:** the first letter of the title, as before. This is the
    default.
  - **On device:** an icon chosen on the phone from about 190 Material icons
    that matches the chat's title. No network.
  - **By Hermes:** your gateway's model picks the icon from the same set.
    Until it answers, a chat shows the on-device match.
- **Mixed shapes.** With icons on, each chat gets one of nine Material 3
  Expressive shapes (cookies, clovers, sunny, burst, flower, pentagon) and a
  colour tone. Both come from the chat's id, so a chat looks the same on
  Home, in Chats and in its title bar. Turn **Mixed shapes** off to put every
  chat on one shape.
- **Relabel all chats** clears Hermes's icons so it picks again. Renaming a
  chat also asks again.

## What By Hermes sends

Only chat titles are sent, in batches of up to 40, to one hidden chat a day
on your connection, named `hermes-android-chat-icons-<date>`. The app hides
that chat everywhere: Home, Chats, the archive and search. The Hermes web
dashboard still lists it. The batch runs as an ordinary agent turn with your
profile's default model. Hermes's reply is accepted only as icon names from
the app's list; anything else is ignored.

## Downloads

Split APKs signed with the fork's key (SHA-256
`E0:D6:DD:B5:D4:09:89:72:DC:F8:8D:FD:23:DF:5E:01:55:28:74:61:47:62:41:3E:E0:0B:B9:8F:A4:05:BB:24`),
so they install over earlier releases of the fork.

- `app-arm64-v8a-release.apk`: most phones
- `app-armeabi-v7a-release.apk`: older 32-bit devices
- `app-x86_64-release.apk`: emulators
