# Hermes (Material You fork) v2.1.31-you.12

Gateway notice rows, on top of [v2.1.31-you.11](v2.1.31-you.11.md). Bead `hmy-lo7`.

## Changed

- **Hermes review / background-complete blobs are now single-line rows** in the
  chat, styled like the tool-call activity rows (icon + one ellipsized line:
  `Hermes review — <text>`), instead of full-width cards.
- **Tap a notice row to open its full text in the bottom detail sheet** — the
  same sheet tool rows use (`showActivityDetailSheet`, new
  `ActivityDetailSheet.notice` variant with selectable text).
- **Notices fall in place chronologically** instead of being pinned at the
  bottom: each notice is anchored to the message on screen when it arrived
  (`GatewayNotice.anchorMessageId`) and inserted right after that message's
  bubble by `buildChatDisplayItems`. Notices with no (or stale) anchor still
  trail at the end. The 20-notice cap and identity dedupe are unchanged.

## Implementation

- `lib/core/models/gateway_insight.dart`: `GatewayNotice.anchorMessageId` +
  `withAnchor`.
- `lib/core/utils/chat_display_items.dart`: chronological notice insertion;
  public `messageRowId`.
- `lib/core/widgets/activity_row.dart`: `ActivityRow.notice` constructor.
- `lib/core/widgets/activity_detail_sheet.dart`: `notice:` variant of the
  detail sheet.
- `lib/core/screens/chat_screen.dart`: anchor set at arrival; renderer uses the
  row + sheet. `GatewayNoticeCard` removed.

## Tests

- New ordering test: an anchored notice lands after its anchor message, an
  unanchored one trails at the end.
- Widget test: notice renders as one line (no card), tap opens the sheet with
  the full text.
