# Hermes (Material You fork) v2.1.31-you.18

Chat rendering fixes for gateway-driven sessions, on top of
[v2.1.31-you.17](v2.1.31-you.17.md). Pair this release with the Mac gateway
running the `feat/coordinator-threads` fork branch (coordinator mode,
thread messaging) — the app clears its "gateway must be updated" banner once
the connected gateway advertises the `coordinator_mode` capability.

## Fixed

- **Tool rows keep their purpose summary after a reload.** Stored tool-result
  rows arrive from history without `args`; the args live on the assistant
  message's `tool_calls`. The chat now joins them by `tool_call_id`, so a
  reloaded turn shows "Terminal: checking repo status" instead of a bare
  "Terminal" row.
- **Reasoning is visible again after a reload.** REST history ships reasoning
  under `reasoning`/`reasoning_content`, which the app never read — only live
  `reasoning.delta` deltas were mapped. Stored reasoning now renders as a
  reasoning step too (collapsed by default, tap to expand; Verbose Mode
  expands all).
- **Self-improvement review notices keep their chronological place.** Notices
  arriving during a live turn used to anchor to a not-yet-stored message (no
  row id), so they stuck to the bottom of the chat. They now anchor to the
  newest stored row at arrival and are re-anchored when history (re)loads.

## Tests

- `flutter analyze` clean; `flutter test` green (activity/display-items
  suites incl. new regression tests for the three fixes above).
