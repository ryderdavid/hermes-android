# Hermes (Material You fork) v2.1.31-you.16

App-bar declutter, on top of [v2.1.31-you.15](v2.1.31-you.15.md).

## Changed

- While sending or streaming, the chat app bar now shows **only the spinner**
  (no live turn-status flavor text). The status text still exists for
  accessibility: it rides the spinner's semantics label, so screen readers
  announce it. Composer unchanged (no status bar there since you.13).

## Implementation

- `lib/core/screens/chat_screen.dart`: app-bar action is now
  `Semantics(label: status, child: ExpressiveLoadingIndicator)`.
- `openspec/specs/chat-composer/spec.md` synced.
- Recovery tests assert the status via `find.bySemanticsLabel`.

## Tests

- `flutter analyze` clean; full `flutter test` green (2138 passed).
