# Hermes (Material You fork) v2.1.31-you.20

Halted-turn fix, on top of [v2.1.31-you.19](v2.1.31-you.19.md).

## Fixed

- **Chats no longer look halted after an approval request.** The app answered
  `-32601` to gateway server→client requests (approval, secret, clarify, sudo,
  agent_credential) whenever no chat could present them immediately — a watched
  session not yet opened, no chat attached, the open chat bound to another
  session, or a second approval arriving while one was showing. The gateway
  withdrew the prompt on `-32601` and ended the turn with no final message, so
  the chat looked stuck until the next user message. Supported requests are
  now always registered; unpresentable ones are held and delivered when a
  listener attaches or a route remounts, a concurrent approval queues behind
  the active one and is promoted when it settles, and leaving a chat holds its
  pending requests instead of failing them. (hmy-v3n, root cause of hmy-fig.)

## Tests

- `flutter analyze` clean; full `flutter test` green (2150 passed), including
  new watched-session and queued-approval cases in `ws_server_requests_test.dart`.
