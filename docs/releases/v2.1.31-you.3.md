# Hermes (Material You fork) v2.1.31-you.3

Fixes the SUDO toggles appearing not to stick, on top of
[v2.1.31-you.2](v2.1.31-you.2.md). OpenSpec change `mac-fetch-sudo-credential`.

## Fixed

- **Toggle feedback.** Flipping "Answer sudo automatically" or "Allow Mac to
  fetch SUDO password" now explains itself when it stays off: a snackbar says
  "Enable cancelled — the toggle stays off." when the biometric/PIN gate is
  refused, or "Save the SUDO password first to enable this." when the save
  dialog is cancelled. Previously a refused gate reverted the switch silently,
  which looked like the check mark not sticking.
- Regression tests cover both toggles persisting on, surviving a reopen of the
  card, and refusing cleanly with the snackbar when the gate says no.
