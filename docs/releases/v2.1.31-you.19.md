# Hermes (Material You fork) v2.1.31-you.19

Session-mark loading animation and harness-marker cleanup, on top of
[v2.1.31-you.18](v2.1.31-you.18.md).

## Changed

- **The session icon now animates while Hermes works.** Instead of a separate
  spinner popping up in the app-bar corner while a turn runs, the chat's
  session mark morphs and spins its background through the Material 3
  Expressive shape sequence (cookie → clover → burst → flower → sunny, the
  same animation as the loading indicator) while the inner icon stays still.
  The live turn-status text still reaches screen readers via a dedicated
  semantics container on the mark. When the turn settles, the mark returns to
  its static shape.

## Fixed

- **Raw `[OUT-OF-BAND USER MESSAGE …]` wrapper no longer renders in chat
  bubbles.** The gateway can store the harness's mid-turn steering wrapper
  verbatim in message content; `messageContentToText` now strips it
  (keeping the user's actual text) for bubbles, export, and tool rows.

## Tests

- `flutter analyze` clean; full `flutter test` green (2148 passed); goldens
  unchanged (221 passed).
