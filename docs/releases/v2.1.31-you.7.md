# Hermes (Material You fork) v2.1.31-you.7

Fullscreen artifact canvas, on top of [v2.1.31-you.6](v2.1.31-you.6.md).
OpenSpec change `fullscreen-artifact-canvas` (branch
`feat/inline-html-artifact-preview`).

## Added

- **Maximize preview**: the inline HTML artifact card's header gains a
  fullscreen button that opens the same sandboxed artifact in a fullscreen
  in-app viewport with WebView pinch-zoom/pan enabled (no on-screen zoom
  buttons) — the "infinite canvas" surface for board/deck-style artifacts.
  Close button or system back dismisses; scroll position in chat is intact.
- The in-bubble preview pane is taller: `ConstrainedBox(minHeight: 240)` +
  16:11 aspect (was fixed 16:10), so content is readable without maximizing.

## Security

Fullscreen mode uses the identical sandbox as the in-bubble pane — file and
content access off, no `JavascriptInterface`, all top-level navigation
prevented, injected CSP unchanged. Zoom is a viewport transform only.

## Tests

- New widget test: maximize opens the fullscreen dialog (close button
  present, preview mounted in both panes) and close dismisses it.
- `flutter analyze` clean; full `flutter test` green; `openspec validate
  fullscreen-artifact-canvas` clean.
