# Hermes (Material You fork) v2.1.31-you.17

Send-key fix for steer-while-streaming, on top of [v2.1.31-you.16](v2.1.31-you.16.md).

## Fixed

- **The send key no longer goes grey while a turn streams.** During streaming
  both `_sending` and `_streaming` are true, and `sendBlocked` included
  `_sending`, which nulled `onSend` and disabled the steer-send button.
  `sendBlocked` now blocks only the pre-stream `_sending` phase
  (`_sending && !_streaming`), matching the `_sendMessage` guard — so while
  streaming with a draft, the steer button is enabled and sends mid-turn
  (steer, since `busy_input_mode: steer` is live).
