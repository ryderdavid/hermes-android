# Hermes (Material You fork) v2.1.30-you.1

First release of the Material You fork of
[rusty4444/hermes-android](https://github.com/rusty4444/hermes-android),
based on upstream v2.1.30 (`63670ab`). It installs beside the upstream app as
**Hermes** (`com.ryderdavid.hermes_you`) and keeps every upstream feature.

## What's new

- **Wallpaper colors.** On Android 12+ the app takes its palette from your
  wallpaper. Settings → Appearance → Color also offers Hermes gold and four
  preset palettes, plus a Pure black option for dark theme.
- **Material 3 throughout.** 40 dp buttons with the filled / tonal / outlined /
  text hierarchy, filled text fields, a surface-container navigation bar,
  left-aligned app bars, the Material 3 type scale in the system font, and one
  shared error state with a standard Retry button.
- **A Messages-style composer.** One rounded field holds attach and dictation;
  Send (or Stop) sits beside it and is never larger than the field. The model
  and spoken-reply controls are compact chips above it.
- **Pixel-style Settings** in rounded groups.
- **Android polish.** Themed (monochrome) launcher icon, a themed launch
  splash with no white flash in dark mode, edge-to-edge drawing with
  transparent system bars, and predictive back.
- **Fork identity.** Updates come from this fork's releases; About links to
  the fork and to upstream.

Move connections over from the upstream app with Settings → Backup & restore.

### Manual smoke testing
Run on a Fire HD 10 tablet (Android 9 / Fire OS, armeabi-v7a) with the
signed release APK, against the repository's synthetic gateway
(`tools/fake_gateway`, loopback via `adb reverse`, test key only):

- [x] Connect to a Hermes Gateway API Server — connection validated and saved.
- [x] Browse sessions — Chats list loads; Home shows its empty state.
- [x] Send a message and receive a streamed response — reply streamed into
  the transcript; Send turned primary on typing and disabled-styled when empty.
- [ ] Open Memory, Cron Jobs, Skills, and Settings — partly: on device,
  Settings loaded the model from the dashboard and Cron showed the shared
  error state (the fixture has no cron endpoint). Memory and Skills were not
  opened on device; their load-failure paths are covered by
  `test/error_state_screens_test.dart`. Check against a real gateway.
- [x] Phone-sized and wider layouts — tablet portrait and landscape on device;
  phone and tablet shells in goldens.
- [x] Appearance — Hermes gold and Green applied instantly, persisted across
  restart, Dark mode applied; Wallpaper shown as unavailable on Android 9.

Found and fixed during the smoke test:

- Changing color or theme after adding the first connection opened a second
  workspace on top of the current screen (Home re-ran its launch-time
  auto-open on any dependency change). Auto-open is now decided once at
  launch; `test/home_auto_navigation_test.dart` covers it.
- Below Android 10 the app cannot draw behind the navigation bar, so the
  transparent bar showed a light window background in dark mode. The bar
  now takes the theme surface when the app is not drawn behind it.

Known limitation: the launch splash follows the system theme and, below
Android 12, the default blue. It cannot read the in-app color or dark-mode
choice, which only applies from the first frame.
