# Hermes (Material You fork) v2.1.31-you.11

Tool activity rows and coordinator threads, on top of v2.1.31-you.10.
Branch `feat/inline-html-artifact-preview`; beads `hmy-h2j` and `hmy-6qr`;
plans in `openspec/changes/tool-activity-rows/` and
`openspec/changes/coordinator-threads/`.

**Not yet checked on a phone.** Both features pass the automated checks
only. The on-device tasks in both plans are still open.

## Tool activity rows

- **One line per tool, in time order.** Each tool call is a single row (an
  icon and the plain-language summary) placed where it happened among the
  agent's messages, both live and in history. The auto-expanding tool card
  is gone, so a new call adds one line and nothing above it moves.
- **Reasoning is a row** labelled with the first line of the reasoning.
- **Finished turns fold** to "Worked for …" above the final answer. Tap it
  to see the steps; back-to-back calls of the same kind group into one row.
- **Detail on tap.** A row opens a sheet with the status, time, command or
  arguments and an output excerpt. A group row lists each call.
- **Verbose Mode is now "Show message metadata"**, a debugging switch in the
  About group. It no longer changes tools or reasoning. Your existing
  setting carries over.

Known gaps:
- A failed tool loaded from history shows as completed (`hmy-h2j.7`). The
  red row appears only for failures seen live.
- A stopped turn that had partial answer text still folds (`hmy-h2j.8`).

## Coordinator threads

Works with the current gateway:
- **Threads strip and sheet.** A chat with background subagents shows them
  under the header with their state. "All" opens a sheet with slot usage,
  stop, Stop all and Pause new threads (gateway-wide).
- **Thread view.** Open a thread to follow its work live, read its stored
  transcript once it finishes, steer it, or stop it.
- **Thread cards.** "Started N threads" and a report card per finished
  thread replace the raw delegated-task text.
- **Hide notification content.** A new switch in notification settings.

Needs the gateway branch `feat/coordinator-threads` (in
`~/Code/hermes-agent-coordinator`, not deployed; see `hmy-6qr.11`). Until
then these stay off:
- **Coordinator mode**, a per-chat toggle in the chat menu, plus a default
  for new chats in Settings. The toggle shows disabled with "gateway must
  be updated".
- **Thread updates and questions**, with Reply and Let coordinator decide.
- **Continue** on a finished thread.
- **Thread name on approvals.**

Known gaps:
- Thread notifications only fire for the chat that is open.
- Cards loaded from history are rebuilt from the message text, because the
  gateway's history endpoint does not return the card metadata. A report
  opened after an app restart may not find its thread's transcript.
- A second approval arriving while one is open in the same chat is refused,
  not queued.
