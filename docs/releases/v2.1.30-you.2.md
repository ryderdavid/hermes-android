# Hermes (Material You fork) v2.1.30-you.2

Fix release on top of [v2.1.30-you.1](v2.1.30-you.1.md), based on upstream
v2.1.30 (`63670ab`).

## Fixed

- The message composer's text and cursor sit in the vertical centre of the
  rounded field. With one line they were 4 dp high, because the text field
  was shorter than the 48 dp pill and put its spare height below the text.
  The whole pill remains the field's touch target.

## Downloads

Split APKs signed with the fork's key (SHA-256
`E0:D6:DD:B5:D4:09:89:72:DC:F8:8D:FD:23:DF:5E:01:55:28:74:61:47:62:41:3E:E0:0B:B9:8F:A4:05:BB:24`),
so they install over v2.1.30-you.1: `app-arm64-v8a-release.apk` for most
phones, `app-armeabi-v7a-release.apk` for older 32-bit devices,
`app-x86_64-release.apk` for emulators.

## Checks

- `flutter analyze` clean; full `flutter test` suite passes, including a new
  regression test for the centring at 1.0×, 1.3× and 2.0× text and the
  accessibility guideline checks (48 dp touch targets).
- `flutter build apk --release --split-per-abi`.
