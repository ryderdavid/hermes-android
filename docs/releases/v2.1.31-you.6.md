# Hermes (Material You fork) v2.1.31-you.6

Inline HTML artifact preview in chat, on top of
[v2.1.31-you.5](v2.1.31-you.5.md). OpenSpec change
`inline-html-artifact-preview` (branch `feat/inline-html-artifact-preview`).

## Added

- `MEDIA:`-delivered `.html`/`.htm` artifacts render as a live preview inside
  the existing media card once the message is final (size cap 5 MiB). The
  preview WebView is sandboxed like the desktop's opaque-origin iframe:
  JavaScript enabled, file/content access off, no `addJavascriptInterface`,
  every top-level navigation prevented, and a strict CSP meta tag injected
  (`default-src 'none'`, scripts/styles from `https:` + inline only,
  `connect-src https:`, `form-action 'none'`). Content loads via
  `loadHtmlString` on an opaque base URL — never `file://`.
- Preview gating and CSP injection live in pure, unit-tested helpers
  (`lib/core/utils/html_artifact_preview.dart`); the card re-downloads and
  re-keys the preview when a streamed ref path changes.
- Non-HTML artifacts are unchanged (raster images still inline, everything
  else download/share). New `webview_flutter` dependency.

## Tests

- `test/html_artifact_preview_test.dart` (gating matrix, CSP injection
  idempotence, UTF-8 decode) and `test/media_artifact_card_test.dart` (preview
  mounts only for final, in-budget HTML refs; re-point re-downloads).
- `flutter analyze` clean; full `flutter test` green (1784 tests).
