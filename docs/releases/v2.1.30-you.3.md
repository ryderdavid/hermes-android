# Hermes (Material You fork) v2.1.30-you.3

The Material 3 Expressive refactor of the front end, on top of
[v2.1.30-you.2](v2.1.30-you.2.md) and based on upstream v2.1.30 (`63670ab`).
The aim is an app that looks native on a current Pixel. The OpenSpec change
is `openspec/changes/expressive-refactor`.

## Changed

- **Expressive kit.** An in-repo set of Material 3 Expressive parts: shape
  marks (cookie, clover, sunny, burst, flower), spring motion tokens, the
  shape-morphing loading indicator, wavy progress, segmented lists, connected
  button groups and split buttons.
- **Theme.** Emphasized type, larger corners, a 64 dp navigation bar with a
  pill indicator, and new FAB, sheet and dialog shapes.
- **Home.** A search bar across the top, a "Needs you" carousel for
  approvals and running chats, and recent chats as a segmented list. Each
  project has its own shape.
- **Projects, Activity and More.** Segmented lists with shape marks and tonal
  icons.
- **Chats.** Filters are a connected button group, and the day groups are
  segmented lists.
- **Chat.**
  - Hermes's replies are no longer in bubbles. Your messages keep a tonal
    bubble.
  - The title bar shows the project's shape and the chat title over the
    model. Tap it to change the model.
  - Spoken replies is a checkable item in the overflow menu.
  - Tool activity uses the shape loading indicator and outcome badges.
  - The composer puts Attach outside the field, and Send morphs into Stop.
- **Approvals.** A bottom sheet with Deny and a split Allow button. The main
  half allows only this command; broader grants are in its menu, each
  described. Always allow still asks for a second tap.
- **Settings.** A large header and a card for the connection. Appearance has
  its own page with:
  - a live preview
  - System, Light and Dark as a connected group
  - color swatches, where the chosen one takes the cookie shape
  - pure black, text size and chat density
- **Loading.** Full-page waits use the shape-morphing loading indicator.

Also included, from the work Hermes did between releases:

- The send and stop button stays clickable for TalkBack.
- Backups cover notification preferences, composer drafts and quick chats.

## Downloads

Split APKs signed with the fork's key (SHA-256
`E0:D6:DD:B5:D4:09:89:72:DC:F8:8D:FD:23:DF:5E:01:55:28:74:61:47:62:41:3E:E0:0B:B9:8F:A4:05:BB:24`),
so they install over earlier releases of the fork.

- `app-arm64-v8a-release.apk`: most phones
- `app-armeabi-v7a-release.apk`: older 32-bit devices
- `app-x86_64-release.apk`: emulators
