# Hermes (Material You fork) v2.1.31-you.1

Adds the stored agent SUDO password with per-connection auto-answer of gateway
sudo requests, based on upstream v2.1.30. The OpenSpec change is
`openspec/changes/store-agent-pseudo-password`.

## New

- **Agent SUDO password.** Settings now has an "Agent SUDO password" card for
  the current connection:
  - **Save SUDO password:** enter your Mac admin (sudo) password twice. It is
    stored through Android Keystore (`flutter_secure_storage`) in a dedicated
    namespace — never in SharedPreferences, files, logs, backups, or the UI.
  - **Answer sudo automatically:** per-connection toggle, off by default.
    Enabling asks for your biometric or device PIN (or re-entering the password
    when neither exists). While on, `sudo` requests from that connection's
    Desktop gateway are answered without the manual dialog — at most once per
    request, falling back to the dialog on any failure.
  - **Audit trail:** every auto-answer is listed with time, connection and
    request id. The password itself is never recorded. Auto-answers are also
    mirrored to a notification when the app is in the background.
  - **Clear saved password:** deletes the credential and turns the toggle off
    immediately.
- The password is only ever sent as the answer to a `sudo` request on the
  connection it was saved for, over that connection's authenticated gateway
  WebSocket — never over the legacy API, in URLs, or in logs. Manual
  sudo/secret prompts behave exactly as before when auto-answer is off.

## Notes

- New dependency: `local_auth` (biometric/PIN gate).
- Settings goldens regenerated for the new card.
