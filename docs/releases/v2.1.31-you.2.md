# Hermes (Material You fork) v2.1.31-you.2

Adds on-demand SUDO password fetch for the paired Mac, on top of
[v2.1.31-you.1](v2.1.31-you.1.md). The OpenSpec change is
`openspec/changes/mac-fetch-sudo-credential`.

## New

- **Allow Mac to fetch SUDO password.** A second per-connection toggle in
  Settings › Agent SUDO password (default off, biometric/PIN gated). When on,
  the paired Mac's Hermes can send an `agent_credential.request` on the
  gateway connection and the phone answers once with the Keystore-stored SUDO
  password — so an unattended agent on the Mac can run sudo through a
  user-provisioned channel. When off (or no password stored), the request is
  refused with no credential material.
- **Audit kinds.** The auto-answered-requests list now labels each entry
  `auto-answer` or `fetch`; fetches are also mirrored to a notification when
  the app is backgrounded. The password value is never recorded.
- **Immediate revocation.** Clearing the password or disabling either toggle
  stops all further answers/fetches on that connection at once.

## Wire contract (for the Mac-side Hermes change)

- Server request: method `agent_credential`, event `agent_credential.request`
  with `request_id`.
- Response: `agent_credential.respond` with `{request_id, value}` on success,
  or `{request_id, error: "fetch_disabled"}` on refusal.
