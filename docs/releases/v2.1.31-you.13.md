# Hermes (Material You fork) v2.1.31-you.13

Composer turn-status bar removed, on top of [v2.1.31-you.12](v2.1.31-you.12.md). Bead `hmy-5kk`.

## Changed

- **The pop-up bar above the composer is gone.** While a turn runs, the composer
  shows just the input row with the Stop key; work-in-progress is represented
  by the timeline activity rows and the spinner in the app bar.
- **The app-bar spinner now carries the live turn status** (the gateway's
  `turnStatus` text, ellipsized, max 96px) while sending or streaming, so no
  information was lost — it moved up top.
- **"Go to end" now stays pinned through late layout settling**: the explicit
  jump reuses the bounded end-alignment loop (frame budget raised 12 → 30), so
  async bubble sizing after the tap no longer leaves the list short of the end.

## Implementation

- `lib/core/widgets/chat_composer.dart`: removed `_buildTurnStatus`, the
  `turnStatus` param/field, and the render branch.
- `lib/core/screens/chat_screen.dart`: app-bar indicator for `_streaming ||
  _sending` with live status text; `_goToEnd()` runs `_startEndAlignment()`
  (shared with initial open); `_initialEndFrameBudget` 12 → 30.
- `test/support/composer_harness.dart`: dropped the `turnStatus` arg.
- Goldens regenerated for the running/streaming composer states.

## Tests

- `flutter analyze` clean; full `flutter test` green (2137 passed).
- Scroll/recovery integration tests pass; goldens updated only for the
  running/streaming composer states.
