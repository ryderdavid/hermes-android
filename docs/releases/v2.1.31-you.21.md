# Hermes (Material You fork) v2.1.31-you.21

Project chats restyle + send-timeout fix, on top of [v2.1.31-you.20](v2.1.31-you.20.md).

## Changed

- **Project Chats tab now matches the main Chats list (M3E).** Rows render as
  `HermesCard`s with the chat's expressive `ChatMark` (morphs while the chat is
  running), a tonal Running/Done `StatusChip` plus relative time, a connected
  All / Recent / Archived filter segment, and date group headers
  (Today / Yesterday / This week / Earlier). The app bar carries the project's
  expressive mark next to the overflow menu. (hmy-nwx)

## Fixed

- **"Send failed: JsonRpcError(prompt.submit): Timeout" while a turn was
  running.** The `prompt.submit` admission ack now waits up to 120s instead of
  the 30s default, in both the recovery coordinator and the legacy desktop
  path. A genuine rejection still answers immediately; only a busy gateway's
  ack waits longer, so accepted submissions no longer surface as send failures.
  (hmy-41x)

## Tests

- `flutter analyze` clean; full `flutter test` green (2154 passed), including
  new project-chats M3E style tests in `project_detail_screen_test.dart`.
