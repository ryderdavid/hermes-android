# Hermes (Material You fork) v2.1.31-you.14

Steer/queue while a turn runs, on top of [v2.1.31-you.13](v2.1.31-you.13.md). Bead `hmy-4lu`.

## Added

- **Send while a turn is streaming.** The composer's main button still becomes
  Stop while Hermes works, but when the draft has text (or attachments) a second
  send button (`composer-steer-send`) appears next to it. Tapping it sends the
  message to the gateway mid-turn; what the text *does* is the gateway's
  `busy_input_mode` (`interrupt` = stop-and-send, the current config default;
  `queue` = run after; `steer` = inject as guidance with a busy-steer ack).
- `ChatScreen._sendMessage` no longer refuses to send while streaming.

## Implementation

- `lib/core/widgets/chat_composer.dart`: steer-send button, driven by a
  `ListenableBuilder` on the text controller so it appears/disappears with the
  draft.
- `lib/core/screens/chat_screen.dart`: send allowed while `_streaming`.
- Widget test: steer button hidden without text, appears with text, taps send.

## Tests

- `flutter analyze` clean; full `flutter test` green (2138 passed).

## Note

For true mid-run steering (guidance without stopping), set
`busy_input_mode: steer` (or call `POST /v1/runs/{id}/steer`) in the gateway
config — the app now surfaces the affordance either way.
