# Hermes (Material You fork) v2.1.31-you.9

Plain-language tool card summaries, on top of
[v2.1.31-you.8](v2.1.31-you.8.md). Branch `feat/inline-html-artifact-preview`;
beads hmy-siw.

## Changed

- **Summaries are sentences, not raw payloads.** `terminal` calls now summarize
  the command in plain words — "Terminal: running the test suite" for
  `flutter test …`, "checking the code for issues" for `flutter analyze`,
  "committing changes" for `git commit …`, "pushing to the remote", "updating
  the issue tracker" for `bd …`, etc. Unrecognized commands fall back to
  "running a shell command". The raw command is still shown in the row's
  detail line. `execute_code`/`browser_exec` use the code's leading `#` comment
  as the step label when present.
- File-ish tools keep naming the object of the call on the same line:
  "Patch: …/gateway_activity_card.dart", "Read file: lib/main.dart",
  "Search files: GatewayActivityCard" — paths/URLs tail-truncated so the file
  name survives.
- The REST streaming path (redacted `label` preview, no raw args) gets the same
  terminal sentence mapping.

## Tests

- `tool_activity_summary_test.dart` rewritten for the sentence mapping:
